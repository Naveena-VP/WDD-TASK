B.Sc Computer Science

B.Sc Computer Science is an undergraduate course that provides students with knowledge of programming, computer applications, databases and software development.

Duration: 3 Years

Eligibility: Passed Higher Secondary Education

Course Type: Undergraduate

Mode: Full Time

Approximate Fees: ₹30,000 per year

Subjects: Java, Python, DBMS, Data Structures, Web Development, Computer Networks

Career Opportunities:
  • Software Developer
  • Web Developer
  • Database Administrator
  • Data Analyst
  • System Administrator
